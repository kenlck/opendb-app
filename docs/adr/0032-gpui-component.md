# UI is Longbridge gpui-component

The Client UI is built with longbridge/gpui-component (Apache-2.0), not raw GPUI controls. DataTable is the Table and Result grid; we still only bind a page of rows (ADR 0017), even though the widget can virtualize and infinite-load. Their editor is the Query editor. Dialogs cover Apply, Schema Change, and close prompts. TabBar is Session Tabs. DockArea and split tiles are out of v1 — Sessions remain native windows. Cell editing for Staged Changes is ours, rendered inside DataTable cells. The crate pins GPUI; we follow that stack. Depend via git, pinned to commits we choose: `gpui-component` at `7acfc184382d30864a688fdaa6c9ff719efc53ae`, and Zed `gpui` / `gpui_platform` at `e0931d5a9dbf4f781b336fdf448739e74a2ac0b5` (the rev that lockfile records). Upgrade both on purpose, not by floating `main`. Not crates.io `0.5.1` (that generation is behind the docs).
